# Scènes TikTok LIVE Studio · New Los Santos RP

Style repris du fond NLS (noir, jaune néon, logo NLS). `apercu-*.jpg` montre le rendu final avec jeu et webcam.

Toutes les images font 1080 × 1920 (format vertical TikTok). Les « cadres » sont transparents : le jeu et la webcam se voient à travers.

| Scène | Sources (de haut en bas dans la liste) |
|---|---|
| 1. Début | Image `1-debut.png` (plein écran) + micro |
| 2. Présentation | Image `2-cadre-presentation.png` · Webcam · Capture de jeu |
| 3. En jeu | Image `3-cadre-en-jeu.png` · Webcam · Capture de jeu |
| 4. Pause | Image `4-pause.png` (plein écran) + micro |
| 5. Fin | Image `5-fin.png` (plein écran) + micro |

Pas de webcam ? Prends les versions `-sans-webcam`.

Placement (voir `guide-placement.png`) :
- Capture du jeu : toute la largeur, du haut du cadre rose (juste sous la zone de l'interface TikTok).
- Webcam : au centre, sous le jeu, dans le cadre arrondi.
- L'image « cadre » doit toujours être **tout en haut** de la liste des sources.
